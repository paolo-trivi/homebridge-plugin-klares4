# Audit archive

Working documents from the stability and compliance work that led to `2.2.0-rc.4`, and the public summary of the review of `2.2.0` that led to `2.3.0`. Names of devices in the older documents are replaced by placeholders (`Device NN`). They describe the code as it was at the time and are kept for reference only; the current behaviour is documented in [`docs/en/`](../en/) and [`docs/it/`](../it/), and user-facing changes are in [`CHANGELOG.md`](../../CHANGELOG.md).
